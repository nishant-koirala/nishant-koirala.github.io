# Nishanta Koirala — Personal Portfolio

A personal portfolio website built with HTML, CSS, and JavaScript. Hosted on GitHub Pages at [nishant-koirala.github.io](https://nishant-koirala.github.io/).

## Sections

- **Home** — Animated hero with particle background and rotating text
- **About** — Personal info and CV download
- **Resume** — Tabbed view of Education, Experience, Skills, and Certifications
- **Projects** — Showcase of personal and client projects
- **Contact** — Contact form (via Formspree) and social links

## Tech Stack

- HTML5, CSS3, JavaScript
- Bootstrap 4
- Particles.js — animated background
- AOS — scroll animations
- Owl Carousel, Magnific Popup, Stellar.js
- Formspree — contact form backend

## Running Locally

No build step required — this is a static site.

```bash
# Python 3
python -m http.server 8080

# Then open
http://127.0.0.1:8080/
```

## Deployment

Deployed automatically via GitHub Pages from the `main` branch. Any push to `main` goes live at [nishant-koirala.github.io](https://nishant-koirala.github.io/).
